# 프로필 메인 화면 정리

## 2026-11-20

소개와 읽기 수준 선택을 가운데 배치하고, 전체 프로젝트 표와 기술·활동 정보를 이어 읽도록 정리했습니다. 단단지 배너, 20개 프로젝트의 기존 설명·주제·링크, LEVEL 1~5의 전체 안내와 같은 수준 연결을 유지했습니다. 다섯 수준 본문·기존 문서·코드·논문·이미지 원본은 수정하지 않았습니다.

| 영역 | 변경 |
| --- | --- |
| 소개 | 가운데 정렬한 이름·짧은 소개·ORCID·논문 연결 |
| LEVEL 1~5 | 다섯 바로가기와 펼쳐 읽는 기존 전체 설명표 |
| 프로젝트 | 기존 9개 주제와 20개 프로젝트의 두 열 표 유지 |
| 기술 | 실제 공개 코드·문서에 대응하는 기술 배지 |
| 활동 | GitHub 공개 기여 활동과 저장소 사용 언어 카드 |

레벨 선택을 큰 굵은 제목으로 한 줄씩 세로 배치하고 색 표시로 구분했습니다. 안내표 설명은 문장마다 줄을 나누고, 모든 표와 셀 내용을 가운데에 배치했습니다.
