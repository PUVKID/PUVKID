# Kwak Yunsuk · 곽윤석

## LEVEL 5 - Expert

컴퓨터 비전과 딥러닝을 연구하고, 소프트웨어를 만듭니다.

[LEVEL 1 - Beginner](%EB%A0%88%EB%B2%A81.md) · [LEVEL 2 - Explorer](%EB%A0%88%EB%B2%A82.md) · [LEVEL 3 - Practitioner](%EB%A0%88%EB%B2%A83.md) · [LEVEL 4 - Advanced](%EB%A0%88%EB%B2%A84.md) · **LEVEL 5 - Expert**

**전문적으로 검토하는 분께** — **평가 프로토콜·측정 근거·재현 조건·한계**를 대조합니다. 원고의 주장, 공개 코드의 구현, 실제 관측 기록이 같은 범위를 설명하는지 검토합니다.

**Python · C# · Arduino · Unity**를 사용합니다. Python은 실험·데이터 처리와 PC 기록에, C#은 Windows 프로그램과 Unity 게임 구현에 사용합니다. Arduino는 센서를 읽는 장치이고 Unity는 게임의 장면과 동작을 구성하는 개발 도구입니다. 아래 표의 기본 기능을 바탕으로 각 수준의 상세 안내로 이어집니다.

같은 프로젝트·차수·원문을 다루며, 레벨은 **설명의 출발점과 깊이**를 뜻합니다. 레벨을 높여야만 자료를 볼 수 있는 구조가 아닙니다. 프로젝트 이름을 누르면 **현재 레벨의 상세 안내**로 이동합니다.

## 차수와 자료를 읽는 순서

1. **프로젝트의 목적과 입력·출력**을 먼저 읽습니다. 무엇을 받는지, 어떤 처리를 하는지, 무엇을 남기는지를 연결합니다.
2. **같은 레벨의 차수별 문서**로 이동합니다. 1차·2차는 개발·실험의 이력이고 LEVEL 1·2는 읽는 수준이므로 서로 다른 구분입니다.
3. **폴더·전체 비교·코드·논문**을 필요에 따라 열어 설명의 근거를 확인합니다. 같은 연구의 이전 원고를 별도 논문 실적으로 더하지 않습니다.
4. **관측 결과와 한계**를 함께 읽습니다. 계획·구현·실행·측정·게재는 각각 다른 상태이며, 하나를 다른 것의 증거로 대신하지 않습니다.

**숫자를 읽을 때:** 정확도·시간·표본 수는 조건과 단위를 같이 확인합니다. 원고에 실린 수치와 후속 실험의 결과를 합치지 않으며, 요약 표시와 저장 원값을 구분합니다.
