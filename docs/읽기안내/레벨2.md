# Kwak Yunsuk · 곽윤석

## LEVEL 2 - Explorer

컴퓨터 비전과 딥러닝을 연구하고, 소프트웨어를 만듭니다.

[LEVEL 1 - Beginner](%EB%A0%88%EB%B2%A81.md) · **LEVEL 2 - Explorer** · [LEVEL 3 - Practitioner](%EB%A0%88%EB%B2%A83.md) · [LEVEL 4 - Advanced](%EB%A0%88%EB%B2%A84.md) · [LEVEL 5 - Expert](%EB%A0%88%EB%B2%A85.md)

**원리를 알아보는 분께** — 각 기능을 연결하는 **개념과 처리 흐름**을 살펴봅니다. 비슷해 보이는 연구도 입력 변환·특징 변환·분류·검출처럼 역할을 나누어 읽습니다.

**Python · C# · Arduino · Unity**를 사용합니다. Python은 실험·데이터 처리와 PC 기록에, C#은 Windows 프로그램과 Unity 게임 구현에 사용합니다. Arduino는 센서를 읽는 장치이고 Unity는 게임의 장면과 동작을 구성하는 개발 도구입니다. 아래 프로젝트의 기본 기능을 바탕으로 각 수준의 상세 안내로 이어집니다.

같은 프로젝트·차수·원문을 다루며, 레벨은 **설명의 출발점과 깊이**를 뜻합니다. 레벨을 높여야만 자료를 볼 수 있는 구조가 아닙니다. 프로젝트 이름을 누르면 **현재 레벨의 상세 안내**로 이동합니다.

## 컴퓨터 비전

컴퓨터가 사진이나 영상에서 **종류·위치·같은 사람 여부**를 구별하도록 만드는 분야입니다. 영상 분류·객체 검출·추적·기하 측정·재식별은 서로 다른 문제이므로 같은 정확도 하나로 묶지 않습니다.

### [**Lung CT Privacy Project**](https://github.com/PUVKID/Lung-CT-Privacy-Project/blob/main/docs/%EC%9D%BD%EA%B8%B0%EC%95%88%EB%82%B4/%EB%A0%88%EB%B2%A82.md)

**접근 방법:** 영상 분류·프라이버시

**이 레벨에서 읽을 내용:** **입력·특징 변환에 따른 폐 CT 분류 성능 비교.** Gaussian Blur는 영상을 부드럽게 흐리고, 블록 재배열은 구역의 위치를 바꿉니다. 입력 영상 변환과 신경망 내부 특징 변환을 구분해 정확도와 프라이버시 지표의 의미를 읽습니다.

### [**Camera Module Anomaly Project**](https://github.com/PUVKID/Camera-Module-Anomaly-Project/blob/main/docs/%EC%9D%BD%EA%B8%B0%EC%95%88%EB%82%B4/%EB%A0%88%EB%B2%A82.md)

**이 레벨에서 읽을 내용:** **YOLO·ViT·CNN으로 카메라 모듈 정상·불량 분류.** YOLO·ViT·CNN이 영상 정보를 다루는 방식과 정상·불량 분류의 차이를 살펴봅니다. 분류 품질, 처리시간, 저장 크기는 서로 다른 비교 기준입니다.

### [**Hole It Project**](https://github.com/PUVKID/Hole-It-Game-Project/blob/main/docs/%EC%9D%BD%EA%B8%B0%EC%95%88%EB%82%B4/%EB%A0%88%EB%B2%A82.md)

**접근 방법:** Unity 게임플레이

**이 레벨에서 읽을 내용:** **물체를 흡수하며 성장하는 게임.** 플레이 상태, 수집 판정, 보상과 화면 전환의 연결을 이해합니다. 게임 데이터가 기기에 저장되는 범위도 함께 봅니다.


## 차수와 자료를 읽는 순서

1. **프로젝트의 목적과 입력·출력**을 먼저 읽습니다. 무엇을 받는지, 어떤 처리를 하는지, 무엇을 남기는지를 연결합니다.
2. **같은 레벨의 차수별 문서**로 이동합니다. 1차·2차는 개발·실험의 이력이고 LEVEL 1·2는 읽는 수준이므로 서로 다른 구분입니다.
3. **폴더·전체 비교·코드·논문**을 필요에 따라 열어 설명의 근거를 확인합니다. 같은 연구의 이전 원고를 별도 논문 실적으로 더하지 않습니다.
4. **관측 결과와 한계**를 함께 읽습니다. 계획·구현·실행·측정·게재는 각각 다른 상태이며, 하나를 다른 것의 증거로 대신하지 않습니다.

**숫자를 읽을 때:** 정확도·시간·표본 수는 조건과 단위를 같이 확인합니다. 원고에 실린 수치와 후속 실험의 결과를 합치지 않으며, 요약 표시와 저장 원값을 구분합니다.
